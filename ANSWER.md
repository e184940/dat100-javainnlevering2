DAT100 basic prog – Assignment 2

This project contains Java solutions for working with arrays and matrices, as part of Assignment 2 in the DAT100 course at HVL.

Contents

no.hvl.dat100.tabeller
Basic operations on 1D arrays:
- Print array
- Convert to string
- Sum elements
- Search and find position
- Reverse array
- Check if sorted
- Merge two arrays

no.hvl.dat100.matriser
Basic operations on 2D arrays (matrices):
- Print matrix
- Convert to string
- Scale matrix by a factor
- Compare matrices
- Transpose (mirror) matrix
- Matrix multiplication

Unit Tests
JUnit 5 tests are provided for both array and matrix functionality to ensure correctness.

How to Run
Compile and run the main methods in each class or run tests with your IDE or build tool (e.g., Maven, Gradle).

Requirements
- Java JDK 17+
- JUnit 5 (for running tests)
